# Yumi Launcher

Лаунчер Minecraft в семействе Yumi: Material 3 Expressive, палитра Glacier из YumiDesktop,
Roboto Flex как в макете (заголовки — wght 820 / wdth 112), живой воксельный 3D-фон
(парящий остров) вместо картинки.

## Что умеет

- **Версии** — список всех версий с серверов Mojang (релизы, снапшоты, старые альфы и беты),
  кэшируется на случай, когда сети нет.
- **Запуск** — скачивает клиент, библиотеки, нативные файлы, ресурсы и нужную версии Java от
  Mojang (8 для старых, 25 для новых), с проверкой SHA-1 и докачкой; запускает игру с
  офлайн-ником. Проверено на 26.3 и 1.12.2.
- **Сборки** — создание, настройка (версия, загрузчик модов и его версия, значок, своя память,
  аргументы Java, размер окна, полный экран), удаление; у каждой своя папка с мирами.
- **Загрузчики модов** — Fabric и Quilt (профиль с их серверов), Forge и NeoForge (их
  официальный установщик, без окна, прямо в папку игры). Проверено: Fabric и Quilt 1.21.1,
  NeoForge 1.21.1, Forge 1.20.1.
- **Моды** — каталог Modrinth и CurseForge под версию и загрузчик сборки, установка с
  обязательными зависимостями, список установленных с включением, выключением и удалением.
  CurseForge требует личный бесплатный ключ (console.curseforge.com), он вводится в настройках.
- **Настройки** — тема (системная, светлая, тёмная) и цвета: оригинальная Glacier или
  пастельные зелёная, розовая и синяя; остров (качество, кадры, камера), память, своя Java, папка
  игры, что делать с лаунчером после запуска.
- **Консоль** — лог игры в реальном времени.
- **Аккаунты** — офлайн-ник или вход через **Ely.by** (логин/пароль, код двухфакторной защиты,
  обновление токена перед запуском). Игра с Ely.by запускается под authlib-injector — свой скин
  и вход на серверы Ely.by. Пароль не хранится, только токен. Microsoft — ещё не сделан.
- **Мои серверы** — сервер из сборки на этом компьютере: Vanilla (`server.jar` Mojang), Fabric
  (серверный лаунчер с их сайта), Quilt, Forge и NeoForge (их установщики с `--installServer`).
  Java та же, что нужна версии. Моды сборки копируются, кроме клиентских (Sodium, Iris…) — сторона
  мода берётся с Modrinth по SHA-1 и из `fabric.mod.json`/`quilt.mod.json`. Запуск и остановка
  (`stop` — мир сохраняется; «Выключить сразу» — на крайний случай), терминал с историей команд,
  игроки онлайн, основные `server.properties` (режим, сложность, PvP, белый список, сид…), вход:
  все / только Ely.by (authlib-injector на сервере) / только лицензия. Адреса для друзей —
  локальная сеть и Radmin VPN / ZeroTier / Hamachi / Tailscale. Закрытие лаунчера при
  работающем сервере сначала останавливает его. Проверено: Vanilla 1.21.1, 26.3 и 1.12.2,
  Fabric/Quilt/NeoForge 1.21.1, Forge 1.20.1 и 1.12.2.
- **Быстрый вход** — чужие серверы по адресу (с SRV-записями), пинг как в меню игры: описание в
  цветах, иконка, игроки, задержка; «Играть» запускает выбранную сборку сразу на сервер
  (Quick Play в 1.20+, `--server/--port` раньше).

## Запуск

```bash
source /e/Projects/.tools/env.sh
export GRADLE_USER_HOME=C:/Users/000/.gradle   # тёплый кэш YumiDesktop: те же версии Compose
./gradlew :app:run
```

Ярлык на рабочем столе, который запускает лаунчер из исходников без консоли (иконка Yumi; при
ошибке сборки покажет путь к `.local/demo.log`):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\make-shortcut.ps1
```

Проверки:

- `--args="--ui-smoke"` — снимает все экраны (главная, сборки, моды, настройки, серверы, вход
  Ely.by) в обеих темах, плюс главную и настройки в каждой пастельной палитре, в `app/.local/screenshots/` и закрывается. Данные — во временной папке,
  настройки не трогает.
- `--args="--launch-test 1.21.1 E:/путь/к/папке Fabric fabric-api sodium"` — без окна скачивает
  версию (и загрузчик, и моды с Modrinth, если указаны) в указанную папку, запускает игру, ждёт
  отрисовки и закрывает её. `--join=host:port` — зайти сразу на сервер, `--injector` — под
  authlib-injector, как с аккаунтом Ely.by.
- `--args="--server-test 1.21.1 E:/путь/к/папке Fabric 25565"` — ставит сервер как экран серверов,
  запускает, пингует, выполняет `list` и останавливает по `stop`.
- `--args="--ping-test mc.hypixel.net"` — пинг серверов, как в быстром входе.

Долгие проверки удобнее гонять из замороженной копии, чтобы правки кода их не ломали:
`./gradlew :app:testBundle`, затем `java -cp "app/build/test-bundle/*" com.yumi.launcher.MainKt --server-test …`.

## Устройство

| Где | Что |
|---|---|
| `core/` | Mojang: список версий, правила, библиотеки, ресурсы, Java-рантаймы, HTTP с докачкой, команда запуска; загрузчики модов; Modrinth и CurseForge; Ely.by и authlib-injector; установка серверов, моды для сервера, пинг серверов |
| `data/` | сборки на диске, модель лаунчера (запуск, остановка, лог), моды сборки, разбор XML-лога игры; свои серверы (процесс, терминал, `server.properties`), список быстрого входа, аккаунт Ely.by |
| `settings/` | настройки в `java.util.prefs` |
| `scene/` | воксельный остров: мир, затенение углов и тени (запекаются при старте), рендер через Skia `drawVertices` |
| `ui/` | окно, главная (со входом Ely.by), сборки, моды, серверы, настройки, консоль, общие компоненты |
